# Silicon UI source

Native React components and CSS modules copied from the official [Silicon UI registry](https://ui.teamofsilicons.com/) on 2026-10-13. Component source is unmodified; app layouts and behavior live outside this directory. The MIT license is included in `LICENSE.txt` and in the exported site's `/silicon-ui-license.txt`.

Registry items: `foundation`, `button`, `badge`, `card`, `code-block`, `copy-button`, `search-field`, `breadcrumb`, `empty-state`, `site-header`, `site-footer`, plus their `segmented-control`, provider, media, copy-feedback and motion-token dependencies.

Each registry item is available at `https://ui.teamofsilicons.com/r/<name>.json`. Registry `components/` paths map into this directory; `blocks/` and `lib/` retain their relative paths so component imports stay native.
